=== NOTES ===

1. Drift is EXACTLY 0 ms for 50/50 mints (set of ms-level diffs: {0}).
   Jupiter firstPool.createdAt and DexScreener pairCreatedAt are the same
   on-chain pool-creation event, just formatted differently (ISO-8601 str
   vs ms epoch). No conversion is needed beyond parsing.

2. graduatedAt is systematically LATER than pair creation (mean +5.5 min,
   max +58.9 min). It records the graduation/migration event (pump.fun
   bonding-curve fill -> PumpSwap, or Meteora pool graduation), NOT the
   launch. Using it as the age clock would UNDERCOUNT token age, which
   would let too-old tokens slip through a max-age gate. Not suitable.

3. MT-547's single case of ~40 min drift (firstPool older than
   pairCreatedAt) was NOT reproduced across these 50 real closed Strategy B
   mints. Likely an edge case: a token whose DexScreener search returns a
   later-created pair (re-listing / second pool on another DEX) where the
   earliest-SOL-pair selection differs, or a token indexed by DexScreener
   from a migration pool while Jupiter tracked an earlier pool.

4. Timestamp mapping for the migration:
   - token age clock  -> Jupiter firstPool.createdAt (== DexScreener pairCreatedAt)
   - graduation time  -> Jupiter graduatedAt (only informational; 28/50 present)
